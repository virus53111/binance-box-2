## Что устарело

Старый workflow проверяет наличие корневого `index.html` и фразы «твоя вселенная кино». Теперь `dogizen` содержит **MURDILIMAX — The Answer Atlas**, собирает сайт в `dist/` и публикует его собственным workflow. Последние проверенные запуски старого workflow завершались ошибкой, поэтому **14.11.2026 отключены его запуска по расписанию и по push**; оставлен только ручной запуск для диагностики.

Перед удалением/отключением:
1. Проверьте **Settings → Pages** в этом репозитории и `dogizen`.
2. Посмотрите, где сейчас закреплён Custom domain `murdilimax.com`.
3. Убедитесь, что `dogizen/.github/workflows/pages.yml` успешно публикует актуальный сайт.
4. Только после подтверждения можно удалить лишний механизм, если он не используется.

**Предлагаемое имя:** `murdilimax-pages-legacy` после проверки Pages.
