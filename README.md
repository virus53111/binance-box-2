# Халява.lv

Адаптивный каталог предложений Латвии. Русский интерфейс, 23 карточки и 12 магазинов. Поиск, категории, тип предложения, сортировка, избранное в localStorage, автоматическое скрытие истёкших акций по дате Europe/Riga. Никаких платных зависимостей, ключей API или аналитических трекеров.

## Открыть

Откройте `dist/index.html` в браузере. Файл самодостаточный: работает без сервера и установки пакетов.

## GitHub Pages

1. Загрузите содержимое этой папки в отдельный репозиторий на ветку `main`.
2. В Settings → Pages выберите Source: GitHub Actions.
3. Запустите workflow Publish Halyava.lv (или сделайте новый коммит).

Публикация бесплатна при подходящем тарифе/видимости репозитория GitHub. В архиве есть `.github/workflows/pages.yml`. Исходники не опубликованы автоматически: в текущем подключении нет операции создания нового репозитория, а существующие проекты пользователя не изменялись.

## Обновить предложения

Редактируйте `offers.json`, затем выполните `python3 build.py`. Результат — `dist/index.html`. Даты и заметку о последней проверке в `template.html` также нужно обновлять после проверки источников. GitHub workflow запускает сборщик при коммите и каждые 6 часов; покрытие источников описано ниже.

Данные проверены по публичным страницам 12.09.2026. Это начальная подборка, не полный рынок и не поток в реальном времени. Сроки известны не для всех записей. Наличие бесплатных вещей не подтверждено у владельцев. Каталоги без подтверждённой конкретной акции помечены отдельно. Подарки за покупку не попадают в фильтр «Бесплатно». Зачёркнутые цены — сведения продавцов, не гарантированная минимальная рыночная цена.

## Источники

Каждая запись содержит ссылку `url` и дату проверки `checked`. Основные: Maxima, Rimi, Lidl, Drogas, Douglas, Notino, K-Senukai, Kurši, DEPO, RD Electronics, Euronics, Atdot.lv и Рижская дума. Независимая подборка; сайт не представляет эти организации. Логотипы и продуктовые фото не копировались.

## Проверка

Проверены синтаксис JavaScript, структура записей, ссылки, даты и типы предложений. Полноценный визуальный прогон в браузере в этой среде не выполнен. WebMCP filter_offers подключается при наличии document.modelContext; в обычных браузерах интерфейс работает без него.

## Автообновление (добавлено)

`refresh.py` — сборщик на стандартной библиотеке Python. GitHub Actions запускает его по расписанию `23 */6 * * *` (UTC), сохраняет `auto-offers.json` и `source-status.json` в репозиторий, собирает сайт и публикует через Pages. Секреты и API-ключи не требуются; используется штатный GITHUB_TOKEN с правом contents:write. Защита ветки может потребовать настройки разрешений для записи; скрипт не обходит её.

Проверенный живой запуск 12.09.2026: Douglas — 28 подарков с условиями покупки; Atdot.lv — 7 объявлений «отдам»; Rimi — 3 ссылки на каталоги. Kurši вернул HTTP 403, RD не отдал распознаваемую разметку. Для этих источников автоматический сбор пока не работает. Maxima, Lidl, K-Senukai, DEPO, Drogas и Euronics пока представлены ручными записями/ссылками, не автоматическим сбором цен. Автоматическое покрытие всех магазинов не реализовано.

Новые записи сохраняют текст условий на языке источника (обычно латышском). Сборщик не генерирует цены и не переводит условия с помощью ИИ. В Atdot исключаются объявления с обнаруженной символической платой, обменом или бронью, но наличие вещи обязательно уточняется у владельца.

Успешная проверка заменяет подборку данного источника. Ошибка не меняет last_success и не стирает кэш. Сайт скрывает конкретные предложения старше 24 часов и истёкшие акции; каталоги остаются доступными. Фильтр архива позволяет открыть устаревшие записи с маркировкой. Страница показывает статус каждого автоматического источника. Главная страница списка Atdot не является полным каталогом всей Латвии.

Локально: `python3 refresh.py`, `python3 -m unittest discover -s tests -v`, `python3 build.py`.

Расписание начнёт работать только после загрузки в default branch GitHub и включения Pages → GitHub Actions. GitHub может задерживать запуск, а в неактивных публичных репозиториях отключать расписания; проверяйте Actions и отметку свежести сайта. Workflow не запущен на GitHub в рамках этой передачи файлов.
