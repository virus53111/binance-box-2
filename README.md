# MURDILIMAX — публикация домена

Публичный адрес: https://murdilimax.com/

Единственный источник кинокаталога и дизайна: https://github.com/virus53111/dogizen

Этот репозиторий сохраняет существующую привязку домена GitHub Pages. Workflow `.github/workflows/pages.yml` берёт ветку `main` репозитория `dogizen` и публикует её без изменения файлов. Исторические исходники сервиса помощи из этого репозитория больше не собираются и не публикуются.

Публикация запускается вручную, при изменении workflow и по существующему расписанию раз в 15 минут (GitHub может задерживать запуски).

Не удалять этот репозиторий до переноса Custom domain в настройках GitHub Pages на `dogizen`: сейчас он обслуживает домен.
