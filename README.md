# Murdilimax — старый служебный репозиторий GitHub Pages

**Статус:** архив старого приложения. **Не удалять весь репозиторий без проверки его использования**. Старый workflow и устаревший `public/CNAME` удалены 14.11.2026.

- **Действующий исходный код Murdilimax:** https://github.com/virus53111/dogizen
- **Домен сайта:** https://murdilimax.com/
- **Здесь:** исторические файлы приложения, но больше нет старого workflow или устаревшей привязки домена в `public/CNAME`.
- **Старый workflow:** удалён после серии неудачных запусков; рабочая публикация выполняется из `dogizen/main`.

## Что устарело

Прежний workflow проверял старую страницу про кино и не подходил для нового сайта. **14.11.2026 он полностью удалён**, включая ручной запуск. Рабочий сайт собирается в `dogizen/dist/` и публикуется собственным GitHub Actions workflow. Проектная старая страница `virus53111.github.io/binance-box-2/` остаётся доступной отдельно, но не обслуживает `murdilimax.com`.

Перед удалением/отключением:
1. Проверьте **Settings → Pages** в этом репозитории и `dogizen`.
2. Посмотрите, где сейчас закреплён Custom domain `murdilimax.com`.
3. Убедитесь, что `dogizen/.github/workflows/pages.yml` успешно публикует актуальный сайт (сборка 14.11.2026 завершилась успешно).
4. Только после подтверждения можно удалить лишний механизм, если он не используется.

**Предлагаемое имя:** `murdilimax-pages-legacy` после проверки Pages.
